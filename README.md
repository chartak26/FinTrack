
# FinTrack — Smart Expense Tracker Dashboard

FinTrack is a fully client-side expense tracking dashboard built with React.js, designed to simplify personal finance management through powerful data visualizations, automated tracking, and a clean intuitive interface. Built for performance — achieving 95+ Lighthouse scores across all metrics.

🌐 **Website**
Feel free to test the application here:
**[Visit FinTrack](https://fin-track-mg7c.vercel.app/)**

---

## ✨ Features

* 📊 Interactive data visualizations powered by Recharts
* ✍️ Automated tracking reducing manual data entry by 75%
* 🗂️ Intuitive expense categorization for clear spending insights
* 🌙 Light/dark theme switching powered by CSS Variables
* 💾 LocalStorage integration for offline data persistence
* ⚡ 95+ Lighthouse score across performance, accessibility & SEO
* 📱 Fully responsive design across desktop, tablet, and mobile
* 🎨 Clean and distraction-free dashboard UI
* 🔄 Real-time dashboard updates as new expenses are added

## ⚙️ Local Development

To run FinTrack locally for development, follow these steps:

### Clone the Repository

```
git clone https://github.com/chartak26/FinTrack.git
```

### ⚛️ Frontend Setup

1. Open the project directory:

```
cd FinTrack
```

2. Install dependencies:

```
npm install
```

3. Start the React development server:

```
npm run dev
```

The frontend server will start on:

```
http://localhost:5173
```

## 🔧 How It Works

1. **Add Expense** — Enter your expense details with amount, category, and date
2. **Auto Categorization** — Expenses are automatically organized into categories for better clarity
3. **Visualize Spending** — View interactive Recharts graphs and charts showing your spending patterns
4. **Track Progress** — Monitor your financial activity over time with real-time dashboard updates
5. **Switch Theme** — Toggle between light and dark mode anytime using CSS Variables theming
6. **Offline Access** — All your data is safely stored in LocalStorage — no internet required

---

## 📝 Note

* No backend or database required — fully client-side application
* All expense data is stored locally in the browser using LocalStorage
* Clearing browser data will reset all saved expenses
* For the best experience, use a modern browser like Chrome or Edge
